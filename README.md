# 2DBattle

ブラウザで動く2D格闘ゲーム。操作はスマブラ式（方向＋ボタン）、勝敗はスト式（体力制・2ラウンド先取）。
CPU対戦 / 2P対戦 / トレーニング / オンライン対戦に対応。

## 起動

```
npm install
npm start        # http://localhost:3000
```

Railway では GitHub 連携でそのままデプロイできる（`npm start`、ポートは `PORT` 環境変数）。

## 操作

| | P1 | P2 |
|---|---|---|
| 移動 / ジャンプ / しゃがみ | A D / W / S | ← → / ↑ / ↓ |
| 弱 / 中 / 強 | J / K / L | , / . / /（テンキー 1 2 3） |
| 技 | U | ;（テンキー 4） |
| 必殺技（ゲージMAX） | I | :（テンキー 5） |

- ガード：後ろ入れ。下段はしゃがみガード、中段（→+強）とジャンプ攻撃は立ちガード
- 投げ：弱+中（ガード不可。地上の相手のみ）。つかまれてから10F以内に弱+中で投げ抜け
- 技：技ボタン＋なし/↓/↑/→ ＝ 波動弾 / スライディング / 昇竜拳 / 突進拳
- ブレイクアッパー：弱+中+強（P1は O、P2は P / テンキー6 でも可）。ゲージ半分を使い、どの技の途中からでも出せて相手を浮かせる
- キャンセル：弱→中→強、通常技→技、技→必殺技
- ジャンプは Space でも可。トレーニング中は R でリセット
- F2：当たり判定・フレーム情報の表示

## キャラクター

モードを選ぶとキャラクター選択画面になる（試合中は Esc で戻る）。操作は全員同じで、技の中身が違う。

| キャラ | タイプ | 特徴 |
|---|---|---|
| ハヤテ | スタンダード | 飛び道具・対空・突進がそろった基本キャラ |
| レンジ | スタンダード（攻め） | 踏み込む強攻撃と多段技。立ち強→前強がつながる。中段は↓技 |
| ゴウザン | 投げ | 体力1200。抜けられない投げ、1発耐える突進。足は遅い |
| ミヅキ | 技巧・コンボ | 2段ジャンプ、空中チェーン、技→技キャンセル、浮かせてジャンプで追撃。体力900 |
| ツルギ | 長剣 | リーチが長く振りが遅い。投げた剣は壁に刺さって爆発。投げている間は弱体化 |
| ホタル | 飛び道具 | 4種類の弾を撃ち分ける。近距離は弱い。体力900 |

キャラのデータは `public/chars.js`。基本技（`BASE_MOVES`）への差分で書いてあるので、数値の調整や新キャラの追加はここだけで済む。

## 構成

| ファイル | 役割 |
|---|---|
| `public/chars.js` | キャラクターと技のデータ |
| `public/sim.js` | ゲーム本体。`step(state, [p1入力, p2入力])` で1フレーム進む。整数演算のみの決定論 |
| `public/net.js` | オンライン同期（ロールバック）。DOM非依存 |
| `public/main.js` | 入力・描画・接続（WebRTC／WebSocket） |
| `server.js` | 静的配信＋相手探し・合図・中継の WebSocket（ルーム制） |
| `test/` | 同期のテスト |

## オンラインの仕組み（ロールバック方式）

互いに「Nフレーム目の入力」だけを送り合う。相手の入力を待たずに「さっきと同じ入力を続けている」と予測して進め、
実際の入力が届いて予測が外れていたら、そのフレームまで巻き戻して計算し直す。

- 自分の操作は回線に関係なく2フレームで反応する。回線が遅いと、相手の動きが少し飛んで見える
- 入力はブラウザ同士が直接送り合う（WebRTC）。サーバーは相手探しと接続の合図だけ
- 直接つながらない回線では、3秒後にサーバー中継（WebSocket）へ自動で切り替わる
- 画面上のステータスに「P2P直結 / サーバー中継」「ping」「先読み（予測で進んでいるフレーム数）」が出る
- URLに `?relay=1` を付けるとサーバー中継を強制できる（動作確認用）

テスト：`npm test`（遅延・ロスのある回線を模擬して、確定状態の一致と速度を確認）

永久コンボ探し：`node test/combo-search.js public all`（全キャラの最長コンボを探索。40ヒットを超えたら「永久」と表示）

`sim.js` を変更するときの決まり：
- 小数・`Math.random()`・時刻を使わない（乱数は `rnd(s)`）
- 状態は `state` の中だけに持つ（グローバル変数に持たない）。巻き戻しで丸ごとコピーするので、関数やクラスのインスタンスを入れない
